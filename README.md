# Md Hossain — Personal IT Portfolio

Personal portfolio of **Md Hossain**, IT Support Specialist (L2/L3) and Systems & Network Administrator based in Dhaka, Bangladesh. Built as a static, custom-coded site with a light-first, cyber-inspired interface.

**Live:** https://mdhossaincloud.github.io/

## What's inside

- `index.html` — single-page portfolio (Hero, Curiosity, Mission Logs, Expertise, Journey, Contact)
- `assets/css/style.css` — design system, light/dark theme, motion
- `assets/js/main.js` — interactions, canvas network, theme toggle, scroll reveals
- `cv/MD_Hossain_CV.pdf` — downloadable CV
- `content/` — reserved for future JSON-based content (projects, articles)

## Tech

- Semantic HTML5
- Modern CSS (custom properties, `color-mix`, `mask-image`)
- Vanilla JavaScript (no framework)
- Canvas 2D for the animated network
- Deployed via GitHub Pages

## Accessibility

- Keyboard-navigable diagram and controls
- `prefers-reduced-motion` respected
- Semantic landmarks and skip link
- Sufficient contrast in both themes

## Content accuracy

All project metrics and outcomes reflect MD Hossain's CV. No confidential IPs, configurations or employer infrastructure details are published.
