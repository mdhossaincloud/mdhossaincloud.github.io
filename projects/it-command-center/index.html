Personal IT Command Center

This website. A static portfolio that explains enterprise infrastructure visually, loads fast on a phone, and only says things that can be backed up.

Source on GitHub

Problem

The previous version (Cyber Command v2) was a clean single page, but it could not show how infrastructure fits together, had no room for project case studies or learning material, and mixed a training certificate with vendor certifications.

Objective

  • Say who I am, what I solve and why I can be trusted within the first screen.
  • Use 3D only where it explains something: how offices, devices and tunnels connect.
  • Stay a plain static site on GitHub Pages, with no framework to maintain.
  • Keep every claim traceable to my CV or a public verification link.

Architecture

Technology decisions

  • No framework. The content is mostly static. Vanilla HTML, CSS and JavaScript keep the site fast and easy to maintain without a build pipeline on the server.
  • 3D without a 3D library. Three.js would add well over 100 KB of compressed JavaScript for a scene of a few dozen devices. Instead, a small script rotates and projects 3D coordinates itself and draws with Canvas 2D. It works in every modern browser, so there is no separate WebGL fallback to maintain.
  • Data-driven lab. Each Infrastructure Lab topic is a data object (nodes, links, steps), drawn by one renderer. Adding a topic means adding data, not code.
  • Self-hosted fonts. Archivo and IBM Plex are served from the site itself: no third-party font requests, and predictable loading.
  • Templated pages. A short Python script adds the shared header, footer and metadata to each page, then the output is committed. GitHub Pages ignores the underscore folder that holds it.

Performance and accessibility

  • The 3D scene pauses when it is off-screen or the tab is hidden, and caps resolution on high-density screens.
  • With reduced motion enabled, the scene and the lab stop animating while staying fully usable.
  • Every interactive element works with a keyboard; the 3D scene has keyboard-accessible highlight controls and a text description.
  • Both themes are designed for readable contrast.

Challenges

  • Separating training certificates from vendor certifications, and showing ongoing study honestly as in progress.
  • Making a 3D scene that adds meaning on a phone without draining the battery.
  • Explaining networking concepts with generic examples, never with employer configurations.

Version 4

  • Home page in eight languages (English, German, French, Spanish, Italian, Portuguese, Dutch and Chinese), each with its own URL and hreflang tags.
  • A portrait that assembles from fragments as it scrolls into view, drawn on a canvas, with a plain image for reduced motion.
  • A short motion loop of traffic between offices, rendered from code to an 8-second, 240 KB MP4 that only plays while visible.
  • Services for businesses in Bangladesh, a featured Fixible IT showcase, achievements and an email composer that stores nothing.

Current status

Version 4, November 2026. Earlier versions remain in the repository history.
