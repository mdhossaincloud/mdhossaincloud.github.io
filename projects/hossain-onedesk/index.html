Hossain OneDesk

An offline-first Windows desktop application for personal productivity and IT task management, built so daily tracking never depends on an internet connection or a subscription.

PythonPySide6SQLiteWindows

Overview

OneDesk is a personal desktop project that I build and use alongside my infrastructure work. It brings task tracking for personal and IT work into one compact Windows application that stores everything locally.

Problem

I needed a lightweight way to track personal and IT tasks without relying on cloud services or paid subscriptions. Most tools either require an account and a connection, or are far heavier than a single person's daily task list needs.

Objective

  • Work fully offline, with data kept on the local machine.
  • Keep the task workflow compact enough for everyday use.
  • Offer selectable themes for comfortable long sessions.
  • Use the project to deepen practical software-development skills.

Architecture

A single Python process: a PySide6 (Qt for Python) interface on top of application logic that reads and writes a local SQLite database. There is no server component and no network dependency.

Implementation

  • Desktop interface built with PySide6.
  • Local persistence in SQLite, so the app starts and works without a connection.
  • Selectable visual themes.
  • A compact task-management workflow designed around daily use.

Current status

A working desktop application that I use for my own task management. The source code is not public, and screenshots will be added once a public build is ready.
