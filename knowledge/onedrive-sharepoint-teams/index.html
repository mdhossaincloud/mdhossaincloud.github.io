OneDrive, SharePoint or Teams: where should a file live?

A simple decision guide for saving files in Microsoft 365, so documents stay findable, shareable and safe when people change roles or leave.

  • LevelBeginner
  • Reading time2 minutes
  • Updated10 November 2026
  • Written byMd. Hossain

On this page

  1. The short answer
  2. How the three connect
  3. Syncing to the PC
  4. Sharing safely
  5. Recovering mistakes

Key takeaways

  • OneDrive is for your own working files; SharePoint is for files a team or department owns.
  • Files shared in a Teams channel are stored in that team's SharePoint site.
  • Files that belong to the company should never live only in one person's OneDrive.
  • Share with people or groups, not with "anyone with the link", unless you mean it.

One of the most common Microsoft 365 problems is not technical at all: nobody knows where the latest version of a file is. A clear rule fixes most of it.

The short answer

If the file is... Save it in... Why
A draft only you are working on OneDrive Private by default, synced to your PC, follows you
Owned by a department (HR policies, price lists, templates) SharePoint site for that department Survives staff changes, permissions by group
Being worked on by a project team that also chats about it Teams channel (stored in SharePoint) Conversation and files in one place
Sent once to an outside person Share a link from OneDrive or SharePoint Avoids email attachments and old copies

OneDrive is mine. SharePoint is ours. Teams is where we talk about it.

How the three connect

  • OneDrive is a personal library in the cloud. Each user typically gets 1 TB. When an employee leaves, their OneDrive is eventually deleted, which is why company records must not live only there.
  • SharePoint stores shared libraries inside sites. Each department or project can have its own site, with permissions set by group.
  • Teams does not have its own file storage. When you upload a file to a channel, it goes into a folder on the team's SharePoint site. Files shared in a one-to-one chat go into the sender's OneDrive.

So Teams is a window onto SharePoint and OneDrive, not a separate place.

Syncing to the PC

The OneDrive sync app can show both OneDrive and SharePoint libraries in File Explorer. Turn on Files On-Demand so files appear in Explorer but only download when opened. This saves disk space, especially on shared or older PCs.

A cloud icon means the file is online only; a green tick means it is available offline.

Sharing safely

When you click Share, you choose who the link works for:

  • Specific people: safest; only the people you name can open it.
  • People in your organisation: anyone with a company account who has the link.
  • Anyone with the link: works for anyone it is forwarded to. Use rarely, and set an expiry date.

Prefer sharing with a group (for example "Accounts team") rather than adding individuals one by one; when someone joins or leaves the group, access updates automatically.

Recovering mistakes

  • Version history: right-click a file → Version history to restore an earlier copy. This also helps after ransomware encrypts synced files.
  • Recycle bin: deleted OneDrive and SharePoint items can usually be restored for 93 days.
  • Restore your OneDrive: rolls back a whole OneDrive to a point in the last 30 days.

These features help, but they are not a full backup strategy. See the 3-2-1 backup rule.
