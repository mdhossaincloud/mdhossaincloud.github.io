    IT glossary

    The terms that come up most in business IT, in one or two plain sentences. The search box above filters this list too.

    Access point AP
    A device that provides Wi-Fi to wired networks. Offices use several, managed together, for even coverage.
    Active Directory AD
    Microsoft's directory for on-premises Windows networks: user accounts, computers, groups and policies. Guide
    Backup
    A separate copy of data kept so it can be restored after deletion, failure or attack. Follow the 3-2-1 rule.
    Bandwidth
    How much data a connection can carry per second, usually in megabits per second (Mbps).
    Conditional Access
    Microsoft Entra rules that decide whether a sign-in is allowed, for example only with MFA or only from company devices.
    DHCP
    The service that automatically gives devices an IP address, gateway and DNS settings when they join a network. Explainer
    DNS
    The internet's phone book: it turns names like microsoft.com into IP addresses. Explainer
    Domain controller DC
    A Windows Server that stores Active Directory and checks every sign-in on the network.
    Endpoint
    Any device people use or that connects to the network: laptops, desktops, phones, printers.
    Entra ID
    Microsoft's cloud identity service (formerly Azure AD) behind every Microsoft 365 sign-in.
    Exchange Online
    The email and calendar service in Microsoft 365.
    Firewall
    A device or service that allows or blocks network traffic according to rules. Explainer
    Gateway
    The router address a device sends traffic to when the destination is on another network, usually the internet.
    Group Policy GPO
    Settings pushed from Active Directory to users and computers, such as password rules or mapped drives.
    Intune
    Microsoft's service for managing and securing laptops and phones from the cloud.
    IP address
    The number that identifies a device on a network, such as 192.168.1.20. Guide
    ISP
    Internet service provider: the company that supplies an office's internet connection.
    LAN / WAN
    A local area network connects devices in one site; a wide area network connects sites to each other. Explainer
    MFA
    Multifactor authentication: a second proof, such as an app approval, on top of the password. Guide
    NAS
    Network-attached storage: a small box of disks on the network, often used for file shares and backups.
    NAT
    Network address translation: lets many private devices share one public internet address.
    NVR
    Network video recorder: records IP cameras over the network. Storage guide
    OneDrive / SharePoint
    Microsoft 365 file storage: OneDrive for personal work files, SharePoint for shared team files. Guide
    Phishing
    A fake message designed to make someone click a link, share a password or send money. Guide
    PoE
    Power over Ethernet: one network cable carries both data and power, common for cameras and access points.
    PowerShell
    Windows' command line and scripting language for automating administration. Guide
    Ransomware
    Malware that encrypts files and demands payment. Offline backups and MFA are the best defences.
    Router
    Moves traffic between networks, for example between the office LAN and the internet. Explainer
    SLA
    Service level agreement: the agreed response and resolution times for support requests.
    Subnet
    A slice of a network defined by an address and mask, such as 10.10.10.0/24.
    Switch
    Connects wired devices within a network and forwards traffic to the right port.
    Ticket
    A recorded support request with its history, owner and status, kept in a help-desk tool such as ServiceNow.
    UPS
    Uninterruptible power supply: batteries that keep equipment running through short power cuts.
    VLAN
    A virtual LAN: separates traffic, such as staff, guests and cameras, on the same physical switches. Explainer
    VPN
    An encrypted tunnel across the internet, linking a user or a whole branch to the office network. Explainer
