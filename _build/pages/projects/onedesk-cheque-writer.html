OneDesk Cheque Writer

A Windows application for printing accurately onto pre-printed Bangladeshi bank cheques, as part of an office financial workflow.

PythonPySide6SQLiteWindows

Overview

Offices that issue many cheques often fill them in by hand, which is slow and error-prone. OneDesk Cheque Writer is a desktop tool that places the date, payee and amount in the right positions on a cheque and prints them directly.

Problem

Each Bangladeshi bank uses its own cheque size and field layout. A printing tool is only useful if it knows exactly where the payee, amount and date boxes sit on each bank's leaf, otherwise the print drifts outside the fields.

Objective

  • Store cheque layouts per bank: size and the position of each fillable field.
  • Let the user enter cheque details once and print them precisely onto the leaf.
  • Keep everything local and offline, in the same style as OneDesk.

Architecture

The application combines a data-entry form with per-bank layout measurements (cheque size and the position of each field) to place every value on the leaf before printing.

Challenges

  • Measuring each bank's cheque precisely enough that printed fields land inside their boxes.

Current status

In development. The source code is private, and screenshots will be published when a stable version is ready.
