让人与系统始终保持连接

我的 IT 职业生涯始于 2018 年，在孟加拉国一家制造企业负责技术支持，保障工厂和办公室 250 多名员工的正常工作。自 2020 年起，我担任 MKR Group 的高级 IT 主管，负责四个地区办公室的用户、网络和安防系统。

我在意的是“看不见”的 IT：网络持续在线，账户的创建与删除准确无误，摄像机不间断录像，文档完整到明天就能让别人顺利接手。

我创办了 Fixible IT，把同样的标准带给孟加拉国的小企业和家庭，提供 IT 服务和科技产品网店。业余时间，我用 Python 开发一些小型 Windows 工具。

以实用的专业能力、合理的自动化和以客户为中心的服务，解决真实的问题。

走进企业服务器机柜

向下滚动，逐一了解让办公室持续运转的设备：从互联网接入到备用电源。

  1. U23

    边界防火墙与路由器

    将办公室接入互联网、过滤流量，并与各分支建立加密 VPN 隧道。

  2. U22

    配线架

    来自工位、摄像头和无线接入点的每根线缆都在这里端接并贴好标签，任何端口几秒内即可追溯。

  3. U20

    核心交换机

    在所有有线设备之间转发流量，并用不同 VLAN 将员工、访客与摄像头隔离。

  4. U15–U18

    服务器

    需要留在本地的文件共享、目录服务和管理工具。

  5. U10–U11

    NVR（网络硬盘录像机）

    在独立网络中录制每台 IP 摄像头，并按约定期限保存录像。

  6. U2–U3

    UPS（不间断电源）

    短时停电时保持设备运行，长时停电时安全关机。

  7. 01001001 01010100

    归根结底：0 与 1

    流经机柜的每封邮件、每个文件、每帧视频，最终都是二进制数据。继续滚动，看它分解消散。
