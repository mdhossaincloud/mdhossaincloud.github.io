从机房到创业者的办公桌

我的 IT 职业生涯始于 2018 年，在孟加拉国一家制造企业负责技术支持，保障工厂和办公室 250 多名员工的正常工作。自 2020 年起，我担任 MKR Group 的高级 IT 主管，负责四个地区办公室的用户、网络和安防系统。

我在意的是“看不见”的 IT：网络持续在线，账户的创建与删除准确无误，摄像机不间断录像，文档完整到明天就能让别人顺利接手。

我创办了 Fixible IT，把同样的标准带给孟加拉国的小企业和家庭，提供 IT 服务和科技产品网店。业余时间，我用 Python 开发一些小型 Windows 工具。

以实用的专业能力、合理的自动化和以客户为中心的服务，解决真实的问题。

面向孟加拉国企业的服务

我每天为一家多地点集团所做的工作，同样可以为办公室、工厂、商店和家庭提供，可直接合作，也可通过 Fixible IT。

可靠的 IT 大多是看不见的：办公室之间流动的数据、按时运行的备份、持续录像的摄像机。我的职责就是让它一直如此。

  • IT 托管支持

    按月或按需为用户、电脑、打印机和邮件提供支持，可在达卡上门或远程处理。

  • 办公网络与 Wi-Fi

    结构化局域网、企业级 Wi-Fi、MikroTik 路由、VLAN 以及分支机构之间的 VPN 互联。

  • Microsoft 365 与企业邮箱

    自有域名邮箱、Microsoft 365 部署与迁移、许可证和用户管理。

  • Active Directory 与 IT 策略

    集中化用户账户、组策略、工作站标准和访问控制。

  • 视频监控与门禁系统

    在网络中统一规划的 IP 摄像机与 NVR，并提供安全的远程查看。

  • 服务器、备份与 IT 资产

    文件服务器、备份流程、资产台账和预防性维护。

  • 新办公室与分支机构建设

    新地点的一站式 IT：工作站、网络、电话、打印机和文档。

  • 网站与定制电脑

    WordPress 与 WooCommerce 网站，以及定制装机和硬件采购。
